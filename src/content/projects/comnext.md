## The challenge

More than 100 webpages across Autodesk domains used static React, Angular and Vue implementations. The migration moved them to a Contentful-driven architecture.

## My contribution

As a full-stack engineer, I worked on the migration alongside backend, asset and CORS workflows across five microservices. Performance work covered content optimization, asset handling, code splitting and build optimization.

The implementation used SSR, React Server Components, lazy loading and CloudFront CDN.

## Reported outcomes

- Improved page load performance by 15–30% through content optimization, asset handling improvements, code splitting, and build optimization.
- Increased Lighthouse performance scores from 60–70 to 80–90 using SSR, React Server Components, lazy loading, and CloudFront CDN.
- Contributed to SEO growth from 1M to 5M+ monthly page views while supporting backend, asset, CORS, and migration workflows across 5 microservices.
