# Directions

Feature decisions, corrections, and change history live here. Each topic records the accepted baseline, how we reached it, and what remains undecided.

## Topics

- [Loading screen and hero](loading-screen.md): shared rounded panel, two-turn page-fold loader in the hero palette, rejected approaches, and the centred dark hero with edge glow, grain, and gradient logo-shape tiles.

## Updating a record

Keep these sections in each topic:

1. **Current direction:** the latest user-approved requirements and status.
2. **Implementation:** relevant files and behavior, checked against the code.
3. **Change history:** dated changes, reasons, corrections, and lessons.
4. **Verification:** checks performed and their limits.
5. **Deferred decisions:** questions intentionally left for later.

Update an existing topic when refining the same feature. Add a new file and index entry for a separate feature. The root [AGENTS.md](../AGENTS.md) instructs agents to read and maintain these records.
