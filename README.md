# Ayush Rameja’s Portfolio (2026)

Live site: https://www.ayush.im

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion
- Lenis (fine-pointer desktop scrolling only)
- Playwright and Axe

## Local setup

```bash
pnpm install
pnpm dev
```

## Environment

`NEXT_PUBLIC_SITE_URL` is optional locally and controls canonical links in production.

## Scripts

- `pnpm dev` — run locally
- `pnpm build` — production build
- `pnpm start` — start production server
- `pnpm lint` — lint
- `pnpm test:e2e` — browser and accessibility checks
