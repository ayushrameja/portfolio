# Circular AR — draft 01

Exploration only; does not replace the approved website logo.

Two 200-unit letterforms use quarter-circle silhouettes, 8-unit dividing gaps, and mirrored quarter-circle counters. The a uses a lower bowl and solid right stem; the r uses an upper bowl and diagonal leg. This trades perfect circular silhouettes for letter recognition.

Import ar-circular-draft.svg into Figma by dragging it onto the canvas. It contains separately named a and r groups, each with four editable filled vector paths. Individual letter files are also included. No fonts or raster images are needed.
